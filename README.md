# Schreibheft
Offlinefähige PWA für Schul-Tablets. Texte bleiben ausschließlich lokal im Browser.

## GitHub Pages
1. Neues öffentliches Repository `schreibheft` erstellen.
2. Alle Dateien dieses Ordners ins Repository-Hauptverzeichnis hochladen.
3. Unter Settings → Pages → Build and deployment: Deploy from a branch, Branch `main`, Folder `/ (root)` auswählen und speichern.
4. Die angezeigte Pages-URL öffnen und mit einem QR-Code-Generator einen QR-Code für diese URL erstellen.
5. Auf den Tablets den QR-Code scannen, die Seite vollständig laden und in Chrome über das Menü zum Startbildschirm hinzufügen/installieren. Danach Flugmodus testen.

**Achtung:** Löschen von Browser-/Website-Daten entfernt auch die gespeicherten Texte. PDF-Druck/Export ist eine manuelle Sicherung. Nicht für sensible Schülerdaten verwenden. Offline-Verfügbarkeit nach erfolgreichem ersten Laden und Cache-Installation prüfen.
